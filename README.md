### 最近在做

正在构建开源项目 **[spark-agent](https://github.com/HazyStar/spark-agent)**（v0.2）：

- 面向 **国内大模型 API** 的迷你 Coding Agent Harness
- **多 Provider**：DeepSeek / 通义 / 智谱 / Kimi / 硅基流动 …
- **强制验证环**：改代码后自动 typecheck / test，失败继续修
- **中文系统提示**：让国内模型在 Agent 循环里更稳

目标不是再做一个 Claude Code 壳，而是验证：国内模型写代码差，很多时候差在 Harness，而不只是模型本身。
